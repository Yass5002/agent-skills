# Agent Skills Monorepo

Curated, production-grade agent skills for web development, technical SEO, UI design, and automated testing.

## 🚀 Quick Install

Install all skills globally:
```bash
npx skills add Yass5002/agent-skills --all -g
```

Install a specific skill:
```bash
npx skills add Yass5002/agent-skills --skill webapp-testing -g
```
